# Multi-LLM Debate Framework
**David vs. Goliath - Achieving High-Parameter Accuracy through Orchestrated Multi-Agent Debate**

This project is a complete research-grade experimental platform that proves whether multiple independent small/medium LLMs collaborating through structured debate can improve reasoning accuracy, factual reliability, and reduce hallucinations compared to a single LLM.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Configure your `.env` with appropriate API keys.
3. Edit model names in `models/model_config.py` (optional).
4. Run the Jupyter Notebook `Multi_LLM_Debate_Framework.ipynb`.
